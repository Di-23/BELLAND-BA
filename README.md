# BELLAND
BELLAND - интеллектуальный туристический агрегатор

**Роль в проекте:** бизнес-аналитик

**Тип проекта:** учебный дипломный проект

**Навыки:** сбор требований, Vision and Scope (V&S), SRS, прототипирование

### О проекте:
BELLAND - это мобильное приложение для персонализированного планирования маршрутов по Беларуси.

**Ключевые функции:**
- построение мультимодальных маршрутов (фильтры по дням, видам транспорта, составу группы);
- визуальные подборки локаций;
- офлайн-доступ к маршрутам и картам.

### Артефакты проекта:
- [V&S] (./BELLAND V&S.pdf) - бизнес-цели, SWOT-анализ, бенчмаркинг, бизнес-риски, use cases
- [SRS] (./BELLAND SRS.pdf) - функциональные требования, атрибуты качества, словарь данных
- прототип, созданный с помощью инструмента DeepSeek (https://di-23.github.io/BELLAND-prototype/) - ссылка на прототип

**Дата завершения:** 10 сентября 2026 года
